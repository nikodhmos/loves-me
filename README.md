# 🌸 Loves me, loves me not

![screenshot](screenshot.png)

## Play (Windows)
1. Go to **[Releases](../../releases/latest)** and download **LovesMe.exe**
2. Double-click it (if Windows warns you: *More info → Run anyway*)

## Play (any computer with Python)
```
pip install pygame
python LovesMe.py
```

## Controls
| Key | Action |
|---|---|
| Click / Space | pluck a petal |
| R | new flower |
| L | English / Greek |
| H | hide hints |
| M | mute |
